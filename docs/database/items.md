# items collection

| フィールド     | 型               | 説明                                                                                                                                                                                                                                                                          |
| -------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_id`          | ObjectId         | 主キー。MongoDB が自動生成                                                                                                                                                                                                                                                    |
| `label`        | String           | 管理番号(`VR-001` など)。一意。テプラで印刷して備品本体に貼り、個体の特定に使う。登録時に `{categoryの先頭3文字(英字は大文字)}-{3桁連番}` で自動採番する(例: `VR-001`、`GPU-002`)。連番は同じ接頭辞の最大番号 +1 とし、削除済みの備品の番号は再利用しない。登録後は変更しない |
| `product_name` | String           | 品名(`Meta Quest 3` など)。同じ品名の備品が複数あってもよい                                                                                                                                                                                                                   |
| `shelf_id`     | ObjectId         | 保管棚(`shelves._id`)                                                                                                                                                                                                                                                         |
| `category`     | String           | ジャンル。種類の制限はない自由な文字列。登録画面の選択肢は frontend 側に持つ(現在は `VR`、`GPU/PC` など8種類)。先頭3文字が `label` の接頭辞になる                                                                                                                             |
| `description`  | String           | 詳細情報                                                                                                                                                                                                                                                                      |
| `image_id`     | ObjectId \| null | 備品画像(`images._id`)                                                                                                                                                                                                                                                        |
| `created_at`   | Date             | 登録日時(UTC)                                                                                                                                                                                                                                                                 |
| `updated_at`   | Date             | 更新日時(UTC)                                                                                                                                                                                                                                                                 |
| `deleted_at`   | Date \| null     | 削除日時(UTC)。`null` でなければ削除済みで、通常の一覧には出さない(論理削除)                                                                                                                                                                                                  |
